# Birthday Surprise Website ❤️

A responsive, romantic birthday website made with plain HTML, CSS and JavaScript.

## Preview on your computer

1. Extract `birthday-surprise.zip`.
2. Open the `birthday-surprise` folder.
3. Double-click `index.html` to open it in a browser.
4. Click **Open your little surprise**.

No build tools or installation are required.

## Add your photos

Place three image files in `assets/photos/` and use these exact names:

- `photo-1.jpg`
- `photo-2.jpg`
- `photo-3.jpg`

Use copies of photos you have permission to share. If your photos are PNG files, either convert them to JPG or update the matching `src` values in `index.html`. For best results, use landscape or portrait photos that are reasonably compressed.

## Personalize the words

Open `index.html` in a text editor and search for:
- `My Love` — her name or nickname
- `Your Favourite Person` — your name or nickname
- The paragraphs inside the `letter-card` — your own message

You can also edit colors and fonts in `style.css`.

## Publish it as a link with GitHub Pages

1. Sign in to GitHub and create a **new public repository**, for example `birthday-surprise`.
2. Upload the contents of this folder (not the ZIP file itself). Ensure `index.html`, `style.css`, `script.js`, and the `assets` folder are at the repository's top level.
3. Open the repository's **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)` folder, then save.
6. Wait for GitHub Pages to publish. The page URL will be shown in Settings → Pages and usually looks like `https://YOUR-USERNAME.github.io/birthday-surprise/`.
7. Open that URL on your phone to test it, then send the link to her.

GitHub's interface can change; if you do not see these exact labels, look for the Pages deployment settings.

## Alternative: Netlify

You can use Netlify's manual deploy/drop option: sign in, create a new site by deploying the extracted project folder, and follow its current upload instructions. It will provide a public URL.

## Before sharing

- Test the link in a private/incognito browser and on a phone.
- Make sure the three photos load.
- Remember that a public website can be visited by anyone who has the URL. Avoid putting private information or intimate photos online.
- The site uses Google Fonts when internet access is available; it falls back to system fonts if they cannot load.
- Music is not included in this starter version.
